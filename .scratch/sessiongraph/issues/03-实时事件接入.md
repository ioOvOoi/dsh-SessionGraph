## Question

实时订阅哪些 Host 事件、如何构建消息/agent 切换节点流?

**研究已完整覆盖**(`docs/dsh-host-event-system-research.md` + `research-dsh-platform.md` §3):
- **核心订阅口**:`ctx.on('session/event', (session, event) => …)`(append 后同步 fire-and-forget;根组合注册收全部 agent/子 agent 的事件)
- **节点判定**:event.type ∈ {user/message, assistant/message, tool/result}(surface 事件)必成节点;assistant/chunk 排除(太密);turn/start|end、step/start|end、compaction/* 作边界/压缩点标记
- **生命周期**:session/created(建点)、session/disposed(删点)、agent/status(运行态标记)、subagent/start|end(agent 切换特殊节点:父→子边,scope carrier = 委派父)
- **反查补全**:ctx.sessionQuery.traceSession/readSession/listEvents + sessionPersistence.readFrom 增量;冷启动重建
- **关联**:session.id === agent.id(ctx.agents.get(session.id))
- **agent 切换语义**:无单一 agent/switch 事件;切换 = subagent/start(父→子)+ 子会话 session/created + 父会话 tool/call
- **数据通道**:Host sessionProjections.onChanged → session/projection 帧 → Client useProjection(key, selector)

## Answer

研究产出即答案(见上)。事件接入方案:Host 插件监听 session/event + session/created|disposed + subagent/start|end,构建节点流;反查用 traceSession/listEvents;Client 经 sessionProjections/useProjection 消费。
