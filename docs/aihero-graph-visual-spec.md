# AI Coding Dictionary 图谱 — 视觉规范(从用户截图提取)

> 来源:用户提供的 4 张截图,均为 aihero.dev/ai-coding-dictionary 的力导向图谱交互界面。
> 本文件替代之前的推断报告,是**真实视觉的精确描述**。

## 1. 整体布局

- **全屏图谱 + 右侧滑出详情面板**的两栏结构
- 图谱区域占约 60% 宽度,详情面板约 40%(点击节点后从右侧滑入)
- 图谱背景:**浅灰米色纹理背景**,有微妙的纸张/纤维质感(非纯白,类似 recycled paper)
- 没有顶部导航栏;左上角有搜索按钮(放大镜图标),右上角有信息按钮(i 图标)
- 底部左侧品牌标识 "AIHero.dev",底部右侧有调色板图标和音量图标

## 2. 力导向图谱(核心)

### 2.1 节点
- **形状**:纯圆形,无边框
- **大小**:不一致,反映节点重要性/连接度——从极小(约 12px 直径)到极大(约 80px 直径)
- **颜色**:灰阶填充,从极浅灰(#d0d0d0 左右)到近纯黑(#1a1a1a);连接度高的节点更黑,低的更浅
- **标签**:节点上方,ALL CAPS,等宽字体(如 Courier/SFMono),字号很小(约 10-12px),颜色为浅灰(#999 左右)
- **选中态**:被选中节点成为辐射中心,外围加白色光环/圆环(halo)

### 2.2 连线(仅选中时显示)
- 默认状态:无可见连线(节点散落如星空)
- 选中节点后:从中心节点向相关节点辐射连线
- **连线样式**:细线(约 1px),部分实线部分虚线/点线,颜色为浅灰
- 有明显的层级:中心→紧密相关(粗/实线)→间接相关(细/虚线)
- 连线上有小点(可能是中间节点或数据点)

### 2.3 布局
- **力导向布局**:节点自由散落,无网格、无对齐
- 整体呈现"星团"或"知识星座"感
- 密集区域聚集(如 SESSION/TOOL/CONTEXT/CALL 聚在中心),外围节点稀疏

### 2.4 动画/过渡
- 点击节点后,图谱可能有平滑过渡(中心节点放大,相关连线渐显)
- 无截图动画细节,但力导向图通常有 physics simulation

## 3. 右侧详情面板

### 3.1 结构(从上到下)
1. **关闭按钮**:右上角 X
2. **分类标签**:小号大写字母,字距加宽(letterspacing),如 "SESSIONS, CONTEXT WINDOWS & TURNS" + 页码 "24/69"
3. **标题**:超大号衬线字体(如 Playfair Display / Georgia),如 "Turn"
4. **简介**:正常字号正文,衬线或无衬线字体,1-2 段
5. **HEARD IN THE WILD**:小号大写分区标题
6. **引用卡片**:左侧竖线,浅灰背景,正常字体
7. **深色回答框**:近黑背景(#1a1a1a),白色文字,内有白色下划线链接/关键词
8. **CONNECTS TO**:小号大写分区标题
9. **药丸标签**:细边框圆角胶囊(如 Agent, Tool, Session),等宽字体
10. **FULL DEFINITION**:小号大写分区标题
11. **定义正文**:大段文字,衬线字体,可折叠("READ MORE ∨")
12. **操作按钮**:深色药丸 "Read full entry ↗" + 浅色药丸 "Share ↗" + "Copy markdown"
13. **底部导航**:PREV / NEXT,带前后词条名

### 3.2 排版
- **标题字体**:大号衬线(serif),极粗(bold),如 "Turn" 用约 48-56px
- **分区标题**:小号(small),全部大写,字母间距加宽,灰色(#999),上方有细灰线分隔
- **正文**:正常字号(16-18px),行高舒适(1.5-1.6),衬线或无衬线
- **代码/术语**:等宽字体(mono),如药丸标签内的 "Tool call"
- **深色引用框**:白色 sans-serif 文字,关键词带白色下划线

## 4. 配色方案(灰阶单色)

- **背景**:浅灰米色(约 #f0ede8 或类似暖灰),有纹理
- **节点**:纯灰阶,从 #d0d0d0(浅)到 #1a1a1a(深黑)
- **标签文字**:浅灰 #999 — #aaa
- **详情面板背景**:白色或极浅灰
- **深色引用框**:#1a1a1a 背景 + 白色文字
- **药丸标签**:白色/透明背景 + 细灰边框 + 深灰文字
- **连线**:浅灰 #ccc — #999
- **分区标题**:浅灰 #999,带细灰分隔线

**没有彩色——整个界面完全灰阶/单色**

## 5. 交互

- 点击节点 → 图谱聚焦到该节点(中心化 + 显示连线) + 右侧滑出详情面板
- 搜索按钮(左上角)→ 搜索节点
- 药丸标签可点击(跳转到相关词条)
- PREV/NEXT 导航(底部)
- "Read full entry" 外链按钮
- 图谱可能支持缩放/拖拽

## 6. 技术推断

- 力导向布局:几乎确定是 **D3-force**(d3-force-directed graph)或类似物理模拟
- 渲染:可能是 **Canvas**(性能)或 **SVG**(交互细节)
- 框架:React(从 AIHero.dev 推断,Next.js可能性高)
- 无 UI 框架依赖可见(Tailwind 未知,视觉很定制)

## 7. 对 SessionGraph 的映射

| AI 词典元素 | SessionGraph 映射 |
|---|---|
| 词条节点 | 消息节点(user/assistant/tool) |
| 节点大小 | 消息重要性(tool调用多=大,纯文本=小) |
| 节点颜色(灰阶) | 消息类型(user=浅灰,assistant=深黑,tool=中灰,agent切换=特殊灰) |
| 无连线(默认) | 默认不显示父子关系 |
| 选中辐射连线 | 选中消息节点→显示其父子+同分支节点连线 |
| 分类标签 | 消息类型标签(USER MESSAGE / ASSISTANT RESPONSE / TOOL CALL) |
| 标题(大衬线) | 消息角色 + 时间 |
| HEARD IN THE WILD | 消息内容摘要 |
| FULL DEFINITION | 消息全文 + 元数据 |
| CONNECTS TO 药丸 | 关联消息(父/子/同分支) |
| 当前路径高亮 | 当前 active 分支的节点更黑/更大,非当前路径变浅 |
